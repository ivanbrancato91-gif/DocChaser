# DocChaser v2.3.0

## Templates & Workflow Builder
- Editable reusable document checklists.
- Reorder, add and remove checklist items.
- Required/optional document rules.
- Template deletion protection when used by existing cases.
- Per-template workflow configuration: AI analysis, missing-document email, correction email, completion email and reminder timing.
- Workflow execution now respects the selected template configuration.
- Owner-only template mutations with same-origin and organization checks.
- Audit events for create, update and delete.
- Mobile-friendly builder UI.
